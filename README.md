# 啵啵泡泡 Bubble Bliss

点开就能玩的网页小游戏（无需安装）。

## GitHub Pages 地址（上传后）

把本文件夹作为仓库根目录推到 GitHub，并开启 Pages 后，链接一般是：

`https://<你的用户名>.github.io/bubble-bliss-web/`

## 怎么上传（2 分钟）

1. 打开 https://github.com/new 新建公开仓库，名字可用 `bubble-bliss-web`
2. 不要勾选 “Add README”（本地已有文件）
3. 在仓库页点 **Add file → Upload files**，把本文件夹里的  
   `index.html`、`app.js`、`app.css`、`audio.js`、`.nojekyll` 全部拖进去，Commit
4. 打开 **Settings → Pages**
5. Source 选 **Deploy from a branch**，Branch 选 `main`，文件夹 `/ (root)`，Save
6. 等 1 分钟，刷新 Pages 设置页，复制生成的网址

注意：GitHub Packages 是给 npm/Docker 安装包用的，不能当游戏网页。可玩链接要用 **GitHub Pages**。
